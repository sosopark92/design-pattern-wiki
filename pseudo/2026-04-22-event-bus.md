# 문제

**시나리오:**
항공사 좌석 예매 시스템이다. 고객이 좌석 예약을 완료하는 순간, 서로 다른 팀이 담당하는 네 가지 후속 작업이 독립적으로 실행되어야 한다: 결제팀은 카드 승인을 처리하고, 마일리지팀은 적립 포인트를 계산해 부여하며, 수하물팀은 위탁 수하물 슬롯을 등록하고, 탑승권팀은 바코드가 포함된 탑승권을 생성해 이메일로 발송한다. 각 팀의 시스템은 독립적으로 배포되며, 앞으로 새로운 서비스(예: 라운지 이용권 발급)가 추가될 수 있다.

**기본 시나리오:**
1. 고객이 항공편 좌석을 선택하고 "예약 확정" 버튼을 누른다
2. `BookingService`가 예약 정보를 DB에 저장하고 좌석을 잠근다
3. 예약 저장 직후, 아래 작업들이 각각 독립적으로 실행되어야 한다:
   - `PaymentService`: 결제 수단으로 항공료 청구
   - `MileageService`: 비행 거리 기반 마일리지 적립
   - `BaggageService`: 수하물 위탁 슬롯 사전 등록
   - `BoardingPassService`: 탑승권 생성 및 이메일 발송
4. `BookingService`가 네 서비스를 직접 호출하면, 새 서비스 추가 시마다 `BookingService` 코드를 수정해야 한다
5. 또한 각 서비스의 실패(예: 결제 실패)가 다른 서비스 실행에 영향을 주면 안 된다

**요구사항:**

1. **핵심 동작:**
   - `EventBus.publish(eventType, payload)` — 이벤트를 버스에 발행한다
   - `EventBus.subscribe(eventType, handler)` — 특정 이벤트 타입에 핸들러를 등록한다
   - `EventBus.unsubscribe(eventType, handler)` — 핸들러 등록을 해지한다
   - `BookingService.confirmBooking(bookingData)` — 예약 저장 후 `booking.confirmed` 이벤트 발행만 하면 끝

2. **정책은 외부에서 주입 가능:**
   - 어떤 서비스가 `booking.confirmed` 이벤트를 구독할지는 `BookingService` 외부(앱 초기화 시점)에서 결정
   - 새 서비스 추가 시 `BookingService` 코드는 수정하지 않아야 함
   - 각 핸들러의 실패는 다른 핸들러에 전파되지 않아야 함

3. **테스트 관점:**
   - `confirmBooking()` 호출 시 `booking.confirmed` 이벤트가 올바른 payload와 함께 발행되는지 확인 (실제 서비스 없이)
   - 핸들러 하나가 예외를 던져도 나머지 핸들러는 정상 실행되는지 확인
   - `unsubscribe` 후에는 해당 핸들러가 더 이상 호출되지 않는지 확인

**예시 사용:**
```
// 앱 초기화 — BookingService는 bus만 알면 됨
bus = EventBus()
bus.subscribe("booking.confirmed", PaymentService.onBookingConfirmed)
bus.subscribe("booking.confirmed", MileageService.onBookingConfirmed)
bus.subscribe("booking.confirmed", BaggageService.onBookingConfirmed)
bus.subscribe("booking.confirmed", BoardingPassService.onBookingConfirmed)

bookingService = BookingService(bus)
bookingService.confirmBooking({
    bookingId: "B001",
    flightId: "KE123",
    userId: "U42",
    seat: "12A",
    totalFare: 320000
})
// → bus.publish("booking.confirmed", { bookingId: "B001", ... }) 한 줄로 끝
// → 네 핸들러가 각자 독립적으로 실행됨

// 새 서비스 추가 — BookingService 코드 수정 없음
bus.subscribe("booking.confirmed", LoungeService.onBookingConfirmed)

// 테스트
fakeBus = FakeEventBus()
testService = BookingService(fakeBus)
testService.confirmBooking({ bookingId: "B002", ... })
assert fakeBus.published == [("booking.confirmed", { bookingId: "B002", ... })]
```

**안티패턴:**
```
class BookingService:
    def confirmBooking(self, bookingData):
        self.db.save(bookingData)
        # 각 서비스를 직접 호출 — 새 서비스마다 여기를 수정해야 함
        PaymentService().charge(bookingData)       # 실패하면 이후 코드 전체 중단
        MileageService().accrue(bookingData)
        BaggageService().register(bookingData)
        BoardingPassService().issue(bookingData)
```
- 이걸 Event Bus Pattern으로 어떻게 고쳐야 할까?
